# Activities

#### **Question 1**

A game's menu contains twelve different buttons. Each button uses a different symbol, and there are no labels explaining what the symbols mean.&#x20;

**Explain one way this interface could be improved and why the improvement would make the game more usable.**

***

#### Question 2

A game uses red text to indicate danger and green text to indicate safety.

**Explain why this could create an accessibility problem and describe one way the developer could address it.**

***

#### **Question 3**

A game is being developed for a touchscreen device used by younger children. During testing, players frequently select the wrong button because several buttons are positioned very close together. Some players also have difficulty reading the small text used in the menus.

**Identify TWO usability or accessibility issues in the interface. For each issue, explain how you could improve it with a design change.**<br>

***

#### Question 4

A game developer has created the following interface:

> The main menu contains large animated buttons with pictures instead of words. When a player selects a button, it changes colour but does not make a sound or display any other feedback. Important game information is communicated using different colours. The controls cannot be changed by the player.

**Evaluate the suitability of this interface for a diverse group of players.**
