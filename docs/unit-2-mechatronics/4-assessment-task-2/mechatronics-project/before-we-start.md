# Before We Start

!!! warning "KEEP IT SIMPLE!"

    This project is about **project management.** You do **NOT** need to have enormously complicated programs to succeed here.


You need to take the following steps to ensure effective documentation and version control:

<div class="gb-step" markdown>
<span class="gb-step-num">1</span>

### Create a GitHub Repository

Keep track of your files by creating a new repo on GitHub to store all of your files. You will need to store your Pico project folder and a **`PROJECT_DEVELOPMENT.md`** file on this repo.&#x20;

On the next page you will have explicit instructions on setting this up.

!!! warning "Keep Everything Accessible!"

    **Remember to make sure the repo is PUBLIC and remember to COMMIT and PUSH every lesson!**


</div>

<div class="gb-step" markdown>
<span class="gb-step-num">2</span>

### **Create Markdown Files**

Document the development process in **`PROJECT_DEVELOPMENT.md`** within your GitHub repository. Ensure clarity by adding comments to your code explaining each function and major steps.

You will need to add code blocks so you can reflect on your testing throughout the process.

[:material-link-variant: Markdown Syntax Guide](https://www.markdownguide.org/basic-syntax/)

</div>

<div class="gb-step" markdown>
<span class="gb-step-num">3</span>

### Commit Changes Regularly

Remember to commit your changes to main branch and push to GitHub regularly to keep your work up to date!

</div>
