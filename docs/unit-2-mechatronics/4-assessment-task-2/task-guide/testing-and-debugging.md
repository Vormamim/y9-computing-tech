# Testing and Debugging

!!! info "Learning Intention"

    * Validate programs using test cases and debug a range of errors
    * Create a record of project development demonstrating iterative design and evaluation
    * Develop and apply test criteria for components of a mechatronic and/or automated system
    * Validate algorithms and programs through tracing and test cases



!!! success "Success Criteria"

    * I can validate my program using test cases and debug a range of errors to ensure it functions correctly.
    * I can create a record of my project development, demonstrating iterative design and evaluation throughout the process.
    * I can develop and apply test criteria to components of a mechatronic and/or automated system, ensuring they meet performance standards.



This is probably the most crucial part of the task. As it is likely your first program was not perfect, you will need to make adjustments by testing and debugging your code.&#x20;

This part is all about **problem solving** and **experimentation.**

For this section you will be required to:

* Choose a test case
* Write a brief outline of what you need to do to meet the requirements of the test case.
* Adjust and test your code until you meet the requirements of the test case.
* **Evaluate** your process.
