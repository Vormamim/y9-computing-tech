# For More Advanced Users

If you feel you have mastered what is in the Grok Academy course, you could pursue three other options it's up to you:

1. **Extend yourself with Python for Beginners videos from Microsoft:**

[:material-link-variant: https://learn.microsoft.com/en-us/shows/intro-to-python-development/?authuser=0&wt.mc_id=python-c9-niner](https://learn.microsoft.com/en-us/shows/intro-to-python-development/?authuser=0&wt.mc_id=python-c9-niner)

2. Go further with **Object-Oriented** programming by learning Classes through **More Python for Beginners videos from Microsoft:**

[:material-link-variant: https://learn.microsoft.com/en-us/shows/more-python-for-beginners/?authuser=0](https://learn.microsoft.com/en-us/shows/more-python-for-beginners/?authuser=0)

3. Instead, learn to create a Graphical User Interface (GUI) with Python using Tkinter:

[:material-link-variant: https://www.pythonguis.com/tkinter/](https://www.pythonguis.com/tkinter/)
