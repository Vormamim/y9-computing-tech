## Algorithms

It is expected that students are able to develop and interpret algorithms represented as pseudocode and flowcharts.

Algorithms are built on three main concepts:

??? note "Sequence"

    This is the main **processes** of your program. Setting variables, running linear routines, making calculations, basic output. User cannot make choices or really interact with the system much at all here.


??? note "Branching / Selection"

    This is where the program makes decisions - think user input and IF statements. This is where the user can begin to influence the program, as the program will make decisions based on input.


??? note "Iteration / Repetition"

    This is where we get to loops to keep certain routines running. A program may keep running until it exits, or certain processes may run until a user does something specific.


Now in terms of our programs, to keep everything efficient in Python we create a **main()** function then reference various other functions in main(). When considering algorithms, we call this a **mainline** and **subroutines.**&#x20;

??? note "Subroutines / Functions"

    A subroutine is essentially a function which is called into the mainline. The algorithm for the subroutine is referenced in the mainline, but is actually created separately. This is similar to how a Python function can be used in the main() function, but is created in a different area.

    This helps to keep our algorithms efficient, readable and useable.&#x20;


It is important to start complex algorithms with a clear, uncluttered mainline. The mainline should reference required subroutines, the details of which are shown in separate algorithms.

Each subroutine should be concise and correctly make use of further subroutines for detailed logic.
