# Introduction to Information Systems

Before we move into learning data analysis, first we need to understand **what** information systems are used for and **why,** as well as the **implications** of using them.&#x20;

<mark style="color:purple;background-color:purple;">**There is no point in applying what you have learned about computer programming if you do not understand what a computer is for.**</mark>

This will take around **two weeks** and will both teach you the **basics of computing,** and how to **structure a paragraph** for a short-answer response.

<mark style="color:orange;background-color:yellow;">As you complete the work, you will need to</mark> <mark style="color:orange;background-color:yellow;"></mark><mark style="color:orange;background-color:yellow;">**write down definitions of key terms**</mark> <mark style="color:orange;background-color:yellow;"></mark><mark style="color:orange;background-color:yellow;">from your teacher's presentation and</mark> <mark style="color:orange;background-color:yellow;"></mark><mark style="color:orange;background-color:yellow;">**complete set questions**</mark> <mark style="color:orange;background-color:yellow;"></mark><mark style="color:orange;background-color:yellow;">each lesson. You will be provided with teacher presentations</mark> <mark style="color:orange;background-color:yellow;"></mark><mark style="color:orange;background-color:yellow;">**and**</mark> <mark style="color:orange;background-color:yellow;"></mark><mark style="color:orange;background-color:yellow;">textbook notes.</mark>

Below outlines what you will learn in the next two weeks:

!!! info "Learning Intentions"

    * Describe the purpose of connecting people and systems
    * Differentiate between data and information
    * Investigate how hardware and software are used to manage, control and secure the movement of, and access to, data in networked digital systems
    * Describe the purpose of analysing data
    * Describe inputs, storage, transmission, processes and outputs in data analysis
    * Represent and store data to facilitate computation, including selecting appropriate data types, understanding data type limitations and structuring data systematically
    * Explore careers in software development
    * Explore interests and careers in analysing data
    * Investigate issues with the use of data, including cyber safety, security, privacy and ethics
    * Investigate data collection and interpretation adhering to privacy and cybersecurity principles, including specify what data is collected, who owns it, and how it will be protected



!!! success "Success Criteria"

    * I can describe the purpose of an information system and a digital system.
    * I can explain the difference between data and information, using examples.
    * I can outline the components and categories of an information system.
    * I can differentiate between input and output devices.
    * I can describe hardware components and storage devices used for computing.
    * I can define software and describe its purpose.
    * I can outline a broad range of software applications.
    * I can differentiate between application and operating system software.
    * I can explain the link between hardware and software performance.
    * I can describe the purpose of analysing data.
    * I can memorise and describe inputs, storage, transmission, processes and outputs in data analysis
    * I can describe a variety of different data types commonly used in information systems.
    * I can describe a broad range of roles in computing
    * I can compare users, developers, operators and management.
    * I can analyse issues with data use including cyber safety, security, privacy and ethics
    * I can explain how data is collected, who owns it, and how it will be protected
