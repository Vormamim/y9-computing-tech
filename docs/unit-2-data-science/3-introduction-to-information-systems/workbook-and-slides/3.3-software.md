# 3.3 Software

!!! info "Learning Intention"

    * Investigate how hardware and software are used to manage, control and secure the movement of, and access to, data in networked digital systems



!!! success "Success Criteria"

    * I can define software and describe its purpose.
    * I can outline a broad range of software applications.
    * I can differentiate between application and operating system software.
    * I can explain the link between hardware and software performance.
