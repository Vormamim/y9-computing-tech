## SEE Model

In Computing Technology, we use the 'State, Explain, Example' model to writing paragraphs. You should use this for all of your booklet work - below is a summary, then the full presentation.

<table><thead><tr><th width="121.6666259765625">Element</th><th width="151.33331298828125">Meaning</th><th width="173.333251953125">Role in Paragraph</th><th width="297.6668701171875">Example Sentence</th></tr></thead><tbody><tr><td>State</td><td>Direct answer</td><td>Addresses question clearly</td><td>Confidentiality is a fundamental principle in secure software design.</td></tr><tr><td>Explain</td><td>Clarifies and expands</td><td>Shows depth of understanding</td><td>Protecting confidentiality prevents unauthorised access and reduces risks such as identity theft.</td></tr><tr><td>Example</td><td>Concrete illustration</td><td>Applies knowledge practically</td><td>For example, online banking apps encrypt user data and require secure logins.</td></tr></tbody></table>
