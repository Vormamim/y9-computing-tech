## Activities

Each activity will have instructions on what work will need to be completed and in what format it must be submitted.

You will submit **all activities** to Google Classroom, but they may not be as a Google Doc. The most common formats will be:

* **GitHub** Repository link
* Microsoft Word Doc / Google Doc
* Compressed (.zip) files
