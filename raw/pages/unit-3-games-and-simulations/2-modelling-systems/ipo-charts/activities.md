# Activities

### Question 1

A game allows the player to move their character using the keyboard. When the player presses **W, A, S or D**, the game changes the character's position accordingly.

<mark style="background-color:$warning;">**Construct an IPO chart for the player movement process.**</mark>

### Question 2

A player selects an item from their inventory. The game checks whether the item can currently be used. If it can be used, the item is removed from the inventory and its effect is applied to the player. The game then displays a message confirming the result.

<mark style="background-color:$warning;">**Construct an IPO chart for the process of using an inventory item.**</mark>

### **Question 3**

When a player finishes a mission, the game receives the player's mission status, current experience points and the reward associated with the mission.

The game checks whether the mission has been completed. If it has, the player's experience is increased by the reward amount and the mission is marked as completed. The game then provides the player with an updated experience total and a message describing the result.

<mark style="background-color:$warning;">**Construct an IPO chart for the mission completion process.**</mark>

### **Question 4**

A player is crafting an item at a workbench. The system receives the **selected recipe**, the **player's inventory**, and the **player's available crafting materials**.

The system checks whether the player has enough materials to craft the selected item. If they do, the required materials are removed from the inventory and the crafted item is added. If they do not have enough materials, the inventory remains unchanged and an appropriate message is produced.

<mark style="background-color:$warning;">**Construct an IPO chart for the crafting process.**</mark>
