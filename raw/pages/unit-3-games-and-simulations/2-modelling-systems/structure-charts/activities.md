# Activities

### Question 1

A school is developing a **Sports Management System**.

The main system needs to manage:

* **Student Management**
* **Team Management**
* **Competition Management**

Student Management is responsible for **Register Student** and **View Student Details**.

Team Management is responsible for **Create Team** and **Manage Team Members**.

Competition Management is responsible for **Schedule Competition** and **Record Results**.

<mark style="background-color:$warning;">**Construct a structure chart for the Sports Management System. Make sure to show how parameters / control variables move around the system.**</mark>

Your structure chart should show:

* The overall system at the top
* The three major modules underneath
* The smaller modules belonging to each major module
* The correct hierarchical relationships

### Question 2

An adventure game is divided into several major systems.

The **Game** contains a **Menu System**, **Gameplay System** and **Save System**.

The Menu System contains **Login System** and **Game Menu**.

The Gameplay System contains **Player Management**, **Environment Management** and **Mission Management**.

Player Management contains **Process Player Input** and **Update Player**.

Environment Management contains **Manage Enemies** and **Manage Items**.

Mission Management contains **Manage Objectives** and **Calculate Rewards**.

The Save System contains **Save Game** and **Load Game**.

<mark style="background-color:$warning;">**Construct a structure chart for the Adventure Game. Make sure to show how parameters / control variables move around the system.**</mark>

Your structure chart should contain **three levels** and clearly show which modules belong to each higher-level module.

### Question 3

You have been asked to design the structure of an **Online Game Platform**.

The system needs to allow players to:

* create and manage their player account
* join and play games
* communicate with other players
* view their scores and achievements
* manage saved game information

<mark style="background-color:$warning;">**Design a structure chart for the Online Game Platform. Make sure to show how parameters / control variables move around the system.**</mark>

Your structure chart must:

* Have **3 levels**
* Begin with the **Online Game Platform** as the top-level module
* Include at least **3 major modules** underneath it
* Include at least **2 sub-modules** under each major module
* Use meaningful module names that describe the responsibility of each module
