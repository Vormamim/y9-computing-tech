# Activities

### Question 1

A **school library system** allows students to borrow and return books.

* Students provide their **student details** and **book requests** to the library system.
* The library system provides **borrowing confirmations** and **due-date information** to students.
* A **librarian** provides **book information** to the system.
* The system sends **overdue notifications** to librarians.

<mark style="background-color:$warning;">**Draw a Level 0 Data Flow Diagram (Context Diagram) for the library system.**</mark>

### Question 2

An **online gaming system** allows players to log in and play multiplayer games.

Players send **login details**, **game input**, and **chat messages** to the system. The system sends **game display**, **login results**, and **game notifications** back to players.

The game also connects to an **Online Gaming Service**. The service provides **player account data** and **match information** to the game. The game sends **game results** and **player updates** to the service.

<mark style="background-color:$warning;">**Construct a Level 0 Data Flow Diagram (Context Diagram) for the online gaming system.**</mark>
