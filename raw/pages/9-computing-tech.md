# 9 Computing Tech

## Welcome to the 9 Computing Tech Course

Welcome to the 9 Computing Tech course! Throughout this course, you will be designing and producing computing solutions in a range of contexts:

* **Python for Data Science**: Harness the power of Python to analyse and interpret complex data sets.
* **Mechatronics Programming**: Learn to control and automate mechanical devices using Raspberry Pi Picos
* **Game Design with Unity**: Create and develop 2D platformer games using Unity.

## GitBook Docs Site&#x20;

All content from this point forward will be presented on this Docs Site hosted on GitBook. All content, activities and videos will be available for you to see as they are uploaded. With this in mind, it is important to note that the site is updated live, meaning you may be able to see lessons which will not be covered until weeks later. So do not feel overwhelmed if you see a lot of content - **your teacher will set the pace!**&#x20;

### Submissons

The only limitation of using GitBook Docs Sites is that you cannot submit work. This means that whilst the activities will be presented using the Docs Site, **you will need to submit your work to Google Classroom.**

It is the hope that this makes content **easier** to access, as Google Classroom will solely be used for **announcements** and **submissions.** This means less clutter on Google Classroom so you can prioritise what is important - **learning!**&#x20;
