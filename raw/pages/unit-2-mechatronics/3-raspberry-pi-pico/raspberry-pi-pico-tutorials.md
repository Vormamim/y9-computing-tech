# Raspberry Pi PICO Tutorials

{% hint style="info" %}

## Learning Intention

* Represent data and code to facilitate computation, including selecting appropriate data types, understanding data type limitations and structuring code systematically
* Represent algorithms using flowcharts and pseudocode
* Design or modify existing algorithms for mechatronic or automated systems
* Interpret and modify existing programs (code) for mechatronic and/or automated systems
* Design and implement modular programs (code) with functions for mechatronic and/or automated systems
* Build a mechatronic system using the preferred design and code in a general-purpose programming language
* Apply selected algorithms and data structures for mechatronic or automated systems
  {% endhint %}

{% hint style="success" %}

## Success Criteria

* **I can** represent and store data correctly in my Pico programs, selecting appropriate data types and structuring my code clearly so it runs reliably on the microcontroller.
* **I can represent and explain algorithms using flowcharts or pseudocode,** then translate them into working code for a mechatronic system.
* **I can** read, interpret and modify existing Pico programs, adjusting variables, inputs/outputs and logic so the system behaves as required.
* **I can** design and implement a modular Pico program using functions, and use it to control hardware components (such as LEDs, sensors or motors) in an automated system.
  {% endhint %}
