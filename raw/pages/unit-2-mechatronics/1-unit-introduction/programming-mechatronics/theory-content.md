# Theory Content

{% hint style="info" %}

## Learning Intentions

Describe mechatronic systems

Investigate the development and impact of a&#x20;mechatronic, robotic&#x20;and/or automated system in a real-world&#x20;application

Describe inputs, storage, transmission,&#x20;processes and outputs in mechatronic&#x20;and automated systems

Select and justify sensors for a&#x20;mechatronic or automated system

Identify mechatronic and automated&#x20;systems that operate through human or&#x20;autonomous control

Consider the social impacts and&#x20;ethical and legal responsibilities&#x20;associated with mechatronic and&#x20;automated systems
{% endhint %}

{% hint style="success" %}

## Success Criteria

I can describe mechatronic&#x20;components

I can provide examples of&#x20;mechatronic systems

I can distinguish between&#x20;mechatronics and robotics

I can describe a range of sensor&#x20;inputs which are commonly used&#x20;in mechatronic systems.

I can explain the purpose of&#x20;specific sensor inputs in a&#x20;mechatronic system.

I can identify and&#x20;describe the purpose&#x20;of actuators

I can distinguish&#x20;between robotic&#x20;outputs

I can distinguish between closed&#x20;loop and open loop control&#x20;systems.

I can explain how a real-world&#x20;control system might function.

I can outline the function of a&#x20;microprocessor.

I can discuss ethical issues&#x20;around the use of robotics.

I can discuss the impact of&#x20;mechatronic, robotic and/or&#x20;automated systems on society.
{% endhint %}
