<summary>What do I need to understand in Python?</summary>

* Output (e.g. print('Hello world'))
* Variables (e.g. age = 15)
* Data Types (e.g. String / Int / Float / Boolean)
* Operators (+ - \* / %)
* Input (e.g. my\_age = int(input())
* Decision Making / Branching (IF/ELIF/ELSE)
* Repetition / Iteration (FOR / WHILE loops)
* Subroutines / Functions (e.g. def my\_function())
* Lists (e.g. fruits = \['apple', 'banana'])
* Dictionaries (e.g. student\_profile = {'name': 'Aaron', 'age': 15}

</details>
