We will also be using two external Python libraries - **Pandas** and **Matplotlib.**&#x20;

### **What is Pandas?**

**Pandas** is a Python library used for data manipulation and analysis. It provides two main data structures — `Series` (for one-dimensional data) and `DataFrame` (for two-dimensional tabular data) — making it easy to clean, filter, group, and analyze data efficiently.

### What is Matplotlib?

**Matplotlib** is a plotting library for Python that allows you to create static, animated, and interactive visualisations. It's commonly used to generate charts like line graphs, bar charts, and histograms to help interpret and present data visually.
