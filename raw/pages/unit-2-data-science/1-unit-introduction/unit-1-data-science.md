# Unit 1 - Data Science

Welcome to Data Science!&#x20;

In this unit, you will first revisit Python programming to ensure you have a full understanding of the Year 8 content. This includes concepts such as output (print), input, IF/ELIF/ELSE, for and while loops, functions, lists and dictionaries.&#x20;

You will then learn about data analysis and use additional Python libraries to complete a data science project where you analyse data of your choosing or creation.&#x20;

This unit will include 1 **assessment task:**

## Assessment Task 1 - Data Science Project

In this task you will extend your knowledge of Python and external libraries and modules in order to create a data analysis system.&#x20;

You will find a dataset of your choice before creating a system to analyse the data and produce meaningful information.&#x20;

This will require you to learn how to use **Pandas** to create and manage dataframes using Python and **Matplotlib** to generate visualisations (charts / graphs) using Python.&#x20;

## No Need To Stress

Try not to worry about all of the above - you will be provided with all the resources you need in order to be successful.&#x20;
