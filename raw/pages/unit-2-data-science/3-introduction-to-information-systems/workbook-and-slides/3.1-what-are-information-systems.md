# 3.1 What are Information Systems?

{% hint style="info" %}

## Learning Intention

* Describe the purpose of connecting people and systems
* Differentiate between data and information
  {% endhint %}

{% hint style="success" %}

## Success Criteria

* I can describe the purpose of an information system and a digital system.
* I can explain the difference between data and information, using examples.
* I can outline the components and categories of an information system.
  {% endhint %}
